# テラの孫の手置き場

Tera's RPG Maker MZ Plugins

RPGツクールMZ向けの自作プラグイン配布サイトです。
制作や演出を少し便利にする、個人制作のプラグインを公開しています。
痒いところに手が届く――そんな“孫の手”をいろいろ置いています。

現在は公開準備中です。公開日と配布URLはまだ確定していません。

- [利用規約](terms.md)
- [サポート方針](support.md)

配布開始後は、サイトの各プラグイン詳細ページから、対応する個別ZIPをダウンロードできます。25本をすべて導入する必要はありません。導入前にゲームのバックアップを取り、各プラグインの注意事項・JSヘルプ・利用規約をご確認ください。

一般利用者向けの不具合報告先はサイトのサポートページに案内します。GoogleフォームはGitHubアカウント不要です。GitHub Issuesは技術的な報告向けとして準備中で、受付開始前です。

不具合報告は歓迎していますが、返信・調査・修正を保証するものではありません。個人情報、パスワード、秘密情報、有料素材などは投稿しないでください。
