サポート方針（詳細）

本サイトでは便宜上、公開主を「作者」と表記していますが、プラグインの実装作業にはChatGPTを使用しています。

公開主自身は専門的なプログラミング知識を有していないため、専門的な知識に基づく正確な技術サポートを提供することはできません。

不具合報告や改善のご提案は歓迎していますが、すべてのケースについて調査・修正・個別対応を保証するものではありません。あらかじめご了承ください。

1. 動作保証について

以下を保証するものではありません。

  • すべての動作環境での正常動作
  • すべての他プラグインとの互換性
  • RPGツクールMZ本体のアップデートへの継続的対応
  • 改変されたプラグインの正常動作
  • 既存セーブデータとの完全な互換性
  • 将来にわたる継続的な利用可能性

導入・更新前にはプロジェクトやセーブデータのバックアップを取り、可能であればテスト用プロジェクトで確認してください。

2. 不具合報告について

一般利用者向けの不具合報告窓口です。GitHubアカウントは不要です。

不具合を報告するGoogleフォーム・新しいタブで開きます

GitHub Issuesは技術的な報告向けの窓口として準備中です。現在は受付開始前です。

不具合報告は歓迎しています。可能な範囲で、症状や発生時の状況を詳しくお伝えいただけると助かります。

  • 対象プラグイン名・バージョン
  • 症状と、発生した操作・状況
  • エラーメッセージやスクリーンショット（あれば）
  • 再現手順（分かれば）
  • 関連しそうな他プラグイン（分かれば）

すべての情報を揃える必要はありません。 ただし、「動きません」などの情報だけでは原因を特定できない場合があります。

報告を受け付けることは、返信・調査・修正・個別対応を約束するものではありません。

3. 他プラグインとの競合について

競合に関する報告も可能ですが、すべての組み合わせへの対応はできません。調査・対応するかどうかは内容と状況に応じて公開主が判断します。他作者のプラグインの改修や、個別環境に合わせた調整は保証しません。

4. 個別サポートについて

導入や設定の代行、ゲーム制作全般の質問、利用者固有の環境への調整、他作者製プラグインの修正、対象外エンジンへの移植などは原則として個別対応を保証しません。

5. 機能追加のご要望・改造依頼について

機能追加のご要望や改造のご相談については、お寄せいただいても構いません。

ただし、対応は公開主の判断によるものとし、内容への関心、必要性、実現可能性、制作状況などを踏まえて判断します。ご要望をいただいたことによって、検討・実装・返信をお約束するものではありません。

個別の制作環境や特定作品のためだけの改造については、原則として個別対応を行っておりません。一方、公開主が有用と判断した提案を既存プラグインの改善や新規プラグインの制作へ取り入れる場合があります。

6. 更新・公開について

アップデート、機能追加、不具合修正、特定期日までの対応、RPGツクールMZ本体更新への追従は保証しません。公開主の判断と制作状況により、更新停止・公開停止・配布終了となる場合があります。

7. お問い合わせへの対応について

すべてのお問い合わせに返信できるとは限らず、対応状況・修正予定も必ずしもお知らせできません。

報告時には個人情報、秘密情報、第三者の有料素材などを不用意に送信しないでください。

8. 利用上のお願い

プラグインの導入・更新・改変は必要なバックアップを取ったうえで行ってください。利用条件・免責事項は、別ページの「利用規約」もご確認ください。
